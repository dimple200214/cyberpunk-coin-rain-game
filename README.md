# ⚡ Cyberpunk Coin Rain - Game Theory Simulator

A Python-based Tkinter arcade game that demonstrates single-agent decision-making under time constraints and risk-reward tradeoffs.

## 🎯 Game Theory Concepts
- **Utility Maximization:** Player aims to maximize score within a 35-second limit.
- **Risk vs Reward:** 
  - 🪙 Gold Coin (+10 pts) - Safe
  - 💎 Diamond (+25 pts) - High Reward
  - 💥 Bomb (-15 pts) - Penalty Risk

## 🚀 How to Run
```bash
python game.py
